# Tabular classification - Explain the prediction

In the previous step we explained the prediction given by the model. Nets4Learning can explain that prediction, so we can get an idea of how the model arrived at it.

Two methods are used to explain the prediction: one that works in a model-agnostic way and another that works by going through the inside of the model. The digit detector is the only one that uses the second method, called **LRP** (*Layer Relevance Propagation*).

Let's continue with the tabular classification example from the previous step. This first image shows the interface where we can ask for the decision to be explained.

![Screenshot: interface to explain the prediction {server}](../images/00-tabular-classification/08-explain-0.png)

In the next image we can see how the explanation weighs each attribute according to how much it contributed: if its contribution was positive the bar will be higher, and if it was negative it will grow from the Y axis towards negative values.

![Screenshot: contribution of each attribute to the prediction {server}](../images/00-tabular-classification/08-explain-1.png)

Further down we can ask for a global explanation of the model, that is, run a given number of samples so that combining the explanations of all of them shows which data have the most influence on the model in general.

![Screenshot: beeswarm chart with the global explanation of the model {server}](../images/00-tabular-classification/08-explain-2.png)

When reading this beeswarm chart, we must consider the colour of each instance drawn in the chart and where it sits on the X axis. If a value contributes positively to the prediction, it moves to the right. Each instance shows its value both by colour (red for a high value and blue for a low value of that feature) and in the interface when you place the cursor over the drawn instance.

![Screenshot: details of an instance when hovering over it {server}](../images/00-tabular-classification/08-explain-3.png)
