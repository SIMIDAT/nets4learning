# 目的

このプロジェクトでは、機械学習によって訓練されたニューラルネットワークが実行できるさまざまなタスクを紹介します。そのために3つのアプローチ（分類、物体識別、画像分類）を取り上げます。以下の各項目では、それぞれのアプローチについて、手法の簡単な説明とその手法でのツールの使い方を説明します。

ニューラルネットワークを学ぶ理由には、次のようなものがあります。

* **実践的な応用**: ニューラルネットワークは、音声認識やコンピュータビジョンからデータ分析、結果の予測まで、幅広い用途で使われています。ニューラルネットワークを学ぶことで、医療、工学、データサイエンス、マーケティングなど多くの分野で役立つスキルを身につけることができます。
* **複雑な問題の解決**: ニューラルネットワークは、多数の変数と非線形な関係を持つ複雑な問題の解決に役立ちます。ニューラルネットワークを学ぶことで、こうした問題に対してより効果的な解決策を開発し、分析の精度と効率を高めることができます。
* **技術革新**: ニューラルネットワークは進化と改良を続ける革新的な技術です。ニューラルネットワークを学ぶことで、機械学習と人工知能の分野における最新の動向や発展に追いつくことができます。

ニューラルネットワークは、人間の脳の働きを模倣した機械学習の一形態です。過去のデータや経験から学習して改善し続けるように設計されており、従来のプログラムでは不可能または非常に困難だった複雑なタスクを機械が実行できるようにします。

まとめると、ニューラルネットワークを学ぶことは、幅広い分野で価値のあるスキルを身につけ、複雑な問題をより効果的に解決し、技術と革新の最新動向に追いつくために重要です。

# 表形式データの分類

## 学習済みモデル

学習済みモデルのセクションにアクセスし、利用可能な2つのモデルのうち1つを選択します。

* 車両の特徴に基づく評価の分類
* 花の特徴に基づく花の種類の分類
* ツールには代表的な例の一覧があり、それを使って特徴量のフォームを変更できます。

どちらのモデルでも、ツールのセクションにアクセスすると、予測する要素の特徴量を編集できます。ツールには動的なフォームがあり、ニューラルネットワークへの入力データの種類を変更できます。

## モデルの学習

ツールには、データセットのクラスと属性を表示するデータビューアと、データモデルを作成・設計・学習・エクスポートするための管理機能があります。

左側には、ニューラルネットワークの各レイヤーを編集するエディタがあります。ネットワークの最後のレイヤーのニューロン数は、予測するクラスの数と同じにする必要があります。

右側には、学習用の各種パラメータを編集するエディタがあります。学習率、エポック数（反復回数）、テストセットサイズ、オプティマイザー（最適化関数）、損失関数、メトリクス関数を設定できます。

「モデルを訓練」ボタンを押すと、ニューラルネットワークの学習が始まります。設定と関数の選択がすべて正しければ、学習したモデルの行が下の表に追加されます。

データモデルを学習させたら、予測を行うことができます。そのために、データセットの特徴量を含む動的なフォームが用意されています。モデルが予測するターゲットクラスとその精度は、学習内容と選択したオプションによって変わります。


# 物体識別

## 学習済みモデル

物体識別には4つのモデルがあります。使い方は簡単で、Webカメラを使うオプションを有効にするか、画像をアップロードするだけです。

ツールのセクションには4つの物体識別モデルがあり、これらのモデルはモバイル端末でも動作するよう最適化されています。

* 顔の形状の識別。
* 顔全体のメッシュの識別。
* 関節の識別。
* 物体の識別（分類器でもあります）。

Webカメラによる識別を有効にすると、検出中の点をリアルタイムで確認できるようにフィルターが有効になります。画像をアップロードするオプションを使う場合は、PNG または JPG 形式のファイルを添付できます。そのファイルは同じセクション内の3つの領域（元の画像、適用されたフィルター、検出結果のフィルターを重ねた画像）に読み込まれます。

# 画像分類

## 学習済みモデル

画像分類のセクションでは、ニューラルネットワークの代表的な2つの例、MNIST の画像セットと一般画像のセットから選択できます。

* MNIST: 数字を識別する画像分類器。
* MobileNet: 1001 のカテゴリを識別できる画像分類器。

MNIST モデルでは、数字を含む画像の一覧から選ぶか、キャンバスに予測したい数字を描くか、数字の画像をアップロードできます。

MobileNet モデルには選択できるサンプル画像の一覧が用意されています。また、ニューラルネットワークに解析・分類させる画像をアップロードすることもできます。

どちらのモデルでも、システムが予測を行い、検出した確率（パーセンテージ）を表示します。
