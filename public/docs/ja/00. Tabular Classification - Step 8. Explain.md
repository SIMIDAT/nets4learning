# 表形式データの分類 - 予測の説明

前のステップでは、モデルが出した予測について説明しました。Nets4Learning ではその予測を説明することができ、モデルがどのようにしてその予測に至ったのかを把握できます。

予測の説明には 2 つの手法を使います。1 つはモデルに依存しない（モデル非依存の）手法で、もう 1 つはモデルの内部をたどっていく手法です。2 つ目の手法である **LRP**（*Layer Relevance Propagation*）を使うのは数字検出器だけです。

前のステップの表形式データの分類の例を続けます。最初の画像は、判断の説明を実行できる画面です。

![スクリーンショット：予測を説明する画面 {server}](../images/00-tabular-classification/08-explain-0.png)

次の画像では、各属性がどれだけ寄与したかに応じて説明が属性を重み付けしている様子がわかります。寄与が正であれば棒は高くなり、負であれば Y 軸から負の方向に伸びます。

![スクリーンショット：予測に対する各属性の寄与 {server}](../images/00-tabular-classification/08-explain-1.png)

さらに下では、モデル全体の説明（グローバルな説明）を選択できます。つまり、指定した数のサンプルを実行し、それらすべての説明を組み合わせることで、モデル全体でどのデータが最も影響しているかを知ることができます。

![スクリーンショット：モデル全体の説明を示すビースウォームプロット {server}](../images/00-tabular-classification/08-explain-2.png)

このビースウォームプロットを読むときは、グラフに描かれた各インスタンスの色と、X 軸上のどの位置にあるかに注目します。予測に正の寄与をする値であれば右側に移動します。各インスタンスは、その値を色（その特徴量の値が高いと赤、低いと青）で示すとともに、描かれたインスタンスにカーソルを重ねると画面上にも表示します。

![スクリーンショット：インスタンスにカーソルを重ねたときの詳細 {server}](../images/00-tabular-classification/08-explain-3.png)
